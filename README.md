# Quiz Application 🎯

A simple Java-based Quiz Application that allows users to answer multiple-choice questions and get their final score.

## 🚀 Features

- Multiple choice questions
- User-friendly console interface
- Automatic score calculation
- Instant result display
- Simple and efficient Java implementation

## 🛠️ Technologies Used

- Java
- OOP Concepts
- Scanner Class
- Conditional Statements
- Loops
